# Bootstrap Portfolio Project

A responsive personal portfolio website created using **Bootstrap 5**, **HTML5**, and **CSS3**. The project is designed to showcase personal work, skills, and contact information in a clean and professional layout.

## 📌 Features

- Responsive layout using Bootstrap grid system
- Navbar, cards, and components from Bootstrap 5
- Smooth scrolling and responsive design for all screen sizes and all modern devices
- Sections: home, about, service, work, blog and contact
- Clean and minimal design

## 🚀 Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Media Queries 
- Font Awesome 
- OOCSS (Object-Oriented CSS)
- BEM (Block Element Modifier) Naming Convention

## 🖥️ Responsive Design

The website works perfectly on all modern devices including:
- 📱 Mobile phones
- 💻 Laptops
- 🖥️ Desktops
- 📲 Tablets
